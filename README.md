# 📚 Analizador LL(1) - Parser para Gramáticas

Un analizador sintáctico LL(1) que calcula conjuntos First/Follow, genera la tabla de análisis sintáctico y valida cadenas.


## 🚀 Instalación y Uso

### **Ejecutar localmente (con Flask)**
```bash
# 1. Clonar repositorio
git clone https://github.com/j4guil4r/llparser_compi.git
cd llparser_compi

# 2. Instalar dependencias
pip install flask

# 3. Iniciar aplicación
python app.py

# 4. Abrir en navegador
http://localhost:5000
